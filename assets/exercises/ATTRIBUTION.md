# Exercise demo GIFs — attribution

The animated demos in this folder are two-frame loops derived from stills in the
[free-exercise-db](https://github.com/yuhonas/free-exercise-db) dataset by
yuhonas, which is MIT licensed:

- dumbbell-bench-press.gif ← Dumbbell_Bench_Press
- dumbbell-shoulder-press.gif ← Dumbbell_Shoulder_Press
- bench-bicep-curl.gif ← Seated_Dumbbell_Curl
- standing-bicep-curl.gif ← Dumbbell_Bicep_Curl
- bench-hammer-curl.gif ← Preacher_Hammer_Dumbbell_Curl
- standing-hammer-curl.gif ← Hammer_Curls
- leg-press.gif ← Leg_Press
- chest-press-machine.gif ← Machine_Bench_Press
- shoulder-press-machine.gif ← Machine_Shoulder_Military_Press
- dumbbell-reverse-curl.gif ← Standing_Dumbbell_Reverse_Curl

The dataset's source imagery originates from bodybuilding.com exercise guides;
free-exercise-db redistributes them under its MIT license terms (see the
dataset's LICENSE.md). Used here for personal, non-commercial form reference.
